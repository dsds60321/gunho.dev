## 📌 **프로젝트 이름**: 테니스 예약 검색 시스템
### **프로젝트 개요**
"테니스 예약 검색 시스템"은 서울 및 경기 지역 공공체육시설에 대한 **테니스 코트 예약 상황**을 실시간으로 제공하는 애플리케이션입니다. 공공 API를 활용하여 전체 예약 현황을 가져오는 동시에, API 응답으로 제공되는 링크를 통해 Selenium 기반의 크롤링을 사용하여 더욱 상세한 예약 정보를 수집 및 제공하도록 설계되었습니다.

---

## **💼 구성**

#### **1. 공공 API 기반 예약 현황 관리**
- **공공 데이터 API 연동:**
   - WebClient를 활용하여 서울 지역 체육시설 예약 정보를 요청하고 응답 데이터를 수집.
   - 데이터를 서비스 로직에서 가공하여 사용자 요청에 따라 유효하고 상세한 정보를 반환.
- **예약 목록 페이징 및 데이터 관리:**
   - 대량의 예약 데이터를 효율적으로 처리하기 위해 API 요청과 응답에 대해 **페이징 처리**를 설계.
   - 공공 API에서 제공하지 않는 예약 세부사항은 추가적인 크롤링으로 강화.

#### **2. Selenium 기반 상세 예약 정보 크롤링**
- **상세 정보 수집:**
   - 공공 API에서 반환한 URL을 기반으로 해당 시설의 상세 예약 가능 일자와 시간 정보를 크롤링.
   - Selenium을 사용해 동적 웹 페이지의 DOM 구조를 읽어 예약 상태를 수집.
   - GUI 없이 실행 가능한 **Headless Chrome** 설정을 통해 서버 환경에서 경량화된 크롤링 실행 가능.
- **크롤링 데이터 병합:**
   - API 데이터와 Selenium 기반의 예약 상세 데이터를 병합하여 사용자 맞춤형 데이터 제공.
   - 실시간 예약 가능 여부를 효율적으로 확인 및 재가공.

#### **3. Redis를 활용한 성능 최적화**
- **캐싱 로직 적용:**
   - Spring Data Redis를 활용하여 예약 현황 데이터를 일정 시간 동안 캐싱.
   - 반복적으로 동일한 요청이 발생하는 경우, 캐싱된 데이터를 반환하여 API 호출 및 크롤링 작업을 최소화.
   - 데이터 유효성을 보장하기 위해 Redis TTL(Time-To-Live) 설정으로 자동 만료 처리.
- **네트워크 부하 감소:**
   - 캐싱을 통해 공공 데이터 API 및 크롤링 요청을 최소화하여 서버 리소스를 절감.

#### **4. WebFlux 기반 비동기 처리**
- **비동기 데이터 처리:**
   - WebClient와 WebFlux를 사용하여 공공 API 및 크롤링 작업에서 비동기 호출을 구현.
   - 사용자 요청이 많아도 빠르고 안정적인 데이터 반환을 보장.
- **Non-blocking 설계:**
   - 크롤링과 API 호출을 병렬적으로 처리하여 성능을 최적화하고, 응답 속도를 개선.

---

### **기술 스택**
- **백엔드 프레임워크:**
   - Java 17, Spring Boot 3.3, Spring Data JPA
- **비동기 프로그래밍:**
   - Spring WebFlux, WebClient
- **크롤링 및 데이터 수집:**
   - Selenium, ChromeDriver (Headless Mode)
- **데이터베이스 및 캐싱:**
   - MariaDB, Spring Data Redis
- **빌드 및 배포:**
   - Gradle 기반 빌드, Docker 환경

---

### **특징 및 장점**
1. **예약 데이터 실시간 제공:**
   - 공공 데이터 API와 Selenium 크롤링 기반으로 사용자가 정확하고 실시간으로 예약 상태를 확인할 수 있도록 개선.
2. **시스템 성능 최적화:**
   - Redis를 활용한 캐싱으로 공공 API와 크롤링 요청에 대한 네트워크 부하를 줄임.
3. **비동기 설계를 통한 빠른 응답:**
   - WebFlux 기반 비동기 처리로 대량의 요청을 안정적으로 처리.
